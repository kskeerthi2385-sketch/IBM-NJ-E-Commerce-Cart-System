# 🛒 E-Commerce Cart System

A simple web-based E-Commerce Cart System developed as a frontend project.

## 📌 About the Project

This project demonstrates a basic online shopping experience with a simple and user-friendly interface.

The project was created to practice web development concepts and build a practical e-commerce application.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- 🛍️ E-commerce shopping interface
- 📦 Product display
- 🛒 Shopping cart interface
- 🎨 Simple and clean design
- 📱 User-friendly layout

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the main HTML file in a web browser.
4. Explore the E-Commerce Cart System.

## 🎯 Purpose

This project helped me improve my frontend development skills and understand how an e-commerce website structure works.
